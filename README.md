# Qwen Duo 12G

**让 27B 语言模型帮你理解需求、写提示词，再自动切换到图像模型出图。单卡 12 GB 显存 + 16 GB 内存，Windows 本地运行。**

**A local prompt-to-image workflow for Windows: a 27B language model interprets your request, then hands the GPU to an image model. Built around 12 GB VRAM and 16 GB RAM.**

## 适合谁 / Who this is for

面向愿意配置本地模型的个人创作者、本地 AI 爱好者，以及想研究小内存部署的开发者。尤其适合：已有 12 GB 级 NVIDIA 显卡、16 GB 内存，暂时不升级硬件，希望把“写提示词、看参考图、生成图片”接起来，并能接受数分钟等待的人。

For creators and local-AI enthusiasts comfortable configuring models, and developers studying memory-constrained deployment. You want one workflow for prompt writing, reference images and rendering on existing hardware, and can accept minutes of waiting.

| 你遇到的问题 / Pain point | 这里提供的做法 / What the project provides |
|---|---|
| 两个模型争抢显存 / Two models compete for VRAM | 总控台依次启动、停止 LLM 与 ComfyUI，完成后回装 LLM / The console sequences LLM and ComfyUI processes, then reloads the LLM |
| 每张图都要写英文提示词、复制粘贴、手动切换 / Manual prompts, copying and switching | 一次提交需求，自动写提示词、切换、出图并保存到桌面 / One request drives prompt authoring, switching and saving the image |
| 想按参考图改图 / Want to work from a reference | 图片同时用于 LLM 理解和图像模型条件生成 / The reference reaches both the vision-capable LLM and image conditioning |
| 显存之外，16 GB 内存也吃紧 / RAM is constrained too | 提供按层卸载、可回收 mmap 页、量化 KV 的配置与账本 / Documented layer offload, reclaimable mmap pages and quantised KV configuration |

## 特色在哪里 / What makes it useful

- **一条完整的本地链路。** 从自然语言需求到图片，模型切换由总控台处理；部署后推理在本机完成。A complete local workflow, with automatic model switching after setup.
- **同时考虑显存与系统内存。** [卸载账本](docs/OFFLOAD.md)和[实测记录](docs/EVIDENCE.md)解释张量放在哪里、哪些页可回收，以及哪些参数曾导致 OOM。The offload ledger and measurements explain where memory goes and which configurations failed.
- **可选参考图与思考档位。** 支持文生图、参考图重绘及五档推理强度请求；档位不是画质保证。Supports text-to-image, reference-guided generation and five reasoning settings; higher settings do not guarantee better images.
- **另有纯对话入口。** 不出图时可使用独立聊天界面。两个入口共享后端，建议一次只用一个。A separate chat interface is included; use one console at a time because they share a backend.

```text
需求 / Brief (+ optional reference image)
  → LLM 理解并写提示词 / interpret and write prompt
  → 停止 LLM，释放显存 / stop LLM
  → ComfyUI 生成并保存图片 / render and save
  → 停止 ComfyUI，回装 LLM / stop ComfyUI and reload LLM
```

## 实测与代价 / Measurements and trade-offs

以下来自仓库已有的参考机记录，**不是本次文档更新重新测得，也不是所有 12 GB 显卡的性能保证**。设备记录为 RTX 3060 Laptop GPU（12288 MiB）、i5-9400F、15.94 GiB RAM；请以实际显存容量核对配置，不要仅按显卡名称判断。完整条件见 [EVIDENCE](docs/EVIDENCE.md) 和 [模型清单](docs/MODELS.md)。

These are existing reference-machine records, not new benchmarks or guarantees for every 12 GB card. Check actual VRAM capacity and the exact model files, not just the GPU name.

| 项目 / Item | 已记录结果 / Recorded result |
|---|---|
| LLM 生成 / Generation | 约 / about **4 tok/s**，SSD 热态 / warm SSD |
| LLM 配置测量点 / Measured configuration | **64,000** context、`-ngl 44`；显存 **11,552 MiB**，系统内存 **96.1%** |
| 1080p 出图段 / Render stage | 1920×1088，约 / about **88 s**，不含切换 / excludes switching |
| 2K 出图段 / Render stage | 2560×1440，约 / about **4.5 min**，不含切换 / excludes switching |
| 一次带参考图的完整流程 / One reference-image run | **6 min 41 s**，包含最终回装 LLM；图片在 **5 min 24 s** 时生成 / includes final LLM reload; image written at 5 min 24 s — [时间线 / timeline](docs/RUN_LOG.md) |

**部署前须知 / Before setup:** 严格串行；内存余量很小；首次部署要下载约 31.3 GiB 权重，建议准备 100 GiB 以上可用磁盘空间（含页面文件及安装余量）。参考图不保证主体细节保真；64K 配置不等于满上下文压力测试。当前仍有参考机绝对路径需要核对，并非克隆后即可运行的一键安装包。

Strictly serial; little spare RAM. Weights total about 31.3 GiB; budget 100 GiB or more free disk space including pagefile and setup headroom. Reference-guided generation does not guarantee identity preservation. The 64K configuration is not a full-context stress test. Some reference-machine paths still need manual adjustment: this is not a one-click installer.

## 开始部署 / Start here

需要 Windows、12 GB 级 NVIDIA GPU、16 GB RAM、SSD、PowerShell 7、Node.js，以及独立获取的 llama.cpp、ComfyUI 和配套权重。Windows 11 有参考机记录；其他配置需要自行验证。

Requires Windows, a 12 GB-class NVIDIA GPU, 16 GB RAM, SSD, PowerShell 7, Node.js, and separately obtained runtimes and weights. The recorded reference system uses Windows 11; validate other configurations yourself.

1. **先核对模型。** 查看[文件名、哈希与版本](docs/MODELS.md)。Check exact models, hashes and runtime versions.
2. **按完整指南部署。** [快速开始与路径映射](TECHNICAL_GUIDE.md#快速开始--quick-start)列出权重来源、目录布局、环境变量及仍然写死的路径。Follow the setup and path mapping, including the hard-coded paths that environment overrides do not cover.
3. **配置完成后再启动。** 从仓库根目录运行下面的出图入口；纯对话入口及 CLI 示例见完整指南。Once setup is complete, launch the image console from the repository root:

```powershell
git clone https://github.com/Jxbbbbbyan/qwen-duo-12g.git
cd qwen-duo-12g
# Complete the linked setup and path mapping before the next command.
node .\orchestrator\orchestrator.mjs
# Open http://127.0.0.1:8090
```

首次尝试可输入“橘猫坐在窗台上晒太阳，水彩风格”。这是建议的试用任务，不是固定输出或速度承诺。
Try “a ginger cat on a sunny windowsill, watercolour style”; outputs and timing vary.
